AI Applications Portfolio – Hayden Hartz
Overview
This repository showcases my coursework and projects from ITAI 2372. The portfolio highlights how artificial intelligence can be applied to real-world problems across industries such as space exploration, healthcare, finance, manufacturing, and government.
Throughout the course, I explored how AI systems can support decision-making, detect patterns, improve efficiency, reduce risk, and address ethical concerns. My work focuses on practical AI applications and the importance of using AI responsibly.
